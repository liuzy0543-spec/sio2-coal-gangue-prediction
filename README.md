# 煤矸石 SiO₂ 含量预测模型

> 用**工业分析 + XRF** 即可获得的少量指标，预测煤矸石的二氧化硅（SiO₂）含量。
> 5 折按来源组分组交叉验证 × 5 个分组种子：**R² = 0.7092 ± 0.0143**，MAE = 4.41 wt%。

---

## 1. 任务与结果

| 项 | 内容 |
|---|---|
| 预测目标 | 煤矸石中 **SiO₂ 含量（wt%）** |
| 输入特征 | LOI（烧失量）、`_den`（闭合分母）、K₂O + 4 个类别字段 |
| 样本量 | **243 条 / 136 个来源组** |
| 模型 | RidgeCV（岭回归，alpha 折内自选） |
| **R²** | **0.7092 ± 0.0143**（范围 0.6913 ~ 0.7234） |
| MAE | **4.41 wt%** |
| RMSE | 6.02 wt% |
| 相对误差中位数 | **−0.33%** |
| \|相对误差\| ≤ 20% | **88.5%** |

### 1.1 五个分组种子的逐次结果

| 分组种子 | R² | MAE | RMSE |
|---|---:|---:|---:|
| 42 | +0.6913 | 4.554 | 6.203 |
| 7 | +0.7084 | 4.380 | 6.028 |
| 2024 | +0.7234 | 4.333 | 5.871 |
| 13 | +0.6996 | 4.486 | 6.119 |
| 99 | +0.7233 | 4.274 | 5.872 |
| **均值 ± sd** | **+0.7092 ± 0.0143** | 4.406 | 6.019 |

### 1.2 相对误差分布（OOF，种子 42）

| 区间 | 占比 |
|---|---:|
| \|相对误差\| ≤ 10% | 63.0% |
| \|相对误差\| ≤ 20% | 88.5% |
| \|相对误差\| ≤ 30% | 94.2% |

> 相对误差定义：`(预测值 − 真实值) / 真实值`。
> 均值 +2.71%、中位数 **−0.33%** —— 说明**基本无系统性偏差**。

## 2. 输入特征说明

### 2.1 三个数值特征

| 特征 | 定义 | 获取方式 | 成本 |
|---|---|---|---|
| **LOI（烧失量）** | 815 ℃ 灼烧失重（GB/T 212） | **马弗炉** | 极低 |
| **`_den`（闭合分母）** | `MgO + K₂O + Na₂O + TiO₂ + SO₃ + LOI` | XRF 五项 + LOI | 低 |
| **K₂O** | 氧化钾 | **XRF** | 低 |

**`_den` 的物理含义**：煤矸石全分析满足

```
Σ四氧化物(SiO₂+Al₂O₃+Fe₂O₃+CaO) + Σ非目标氧化物(MgO+K₂O+Na₂O+TiO₂+SO₃) + LOI ≈ 100
```

因此 `100 − _den` 近似等于四氧化物的总量份额。`_den` 越低 → 四氧化物占比越高。

> **无标签泄露**：`_den` 只由**非目标**字段构成，不含 SiO₂/Al₂O₃/Fe₂O₃/CaO 任何信息。

### 2.2 四个类别特征

`province`（省）、`city`（市）、`gangue_source_type`（矸石类型）、`material_stage`（原矸/洗矸）

全部 OneHot 编码（`min_frequency=2`，`handle_unknown="ignore"`）。

### 2.3 为什么用这三个数值特征

| 特征 | 与 SiO₂ 的组内相关（去组间均值） | 说明 |
|---|---:|---|
| LOI | **−0.722** | 烧失量高 → 有机质/黏土多 → 硅低 |
| K₂O | **+0.394** | 钾长石/伊利石与石英共生 |
| `_den` | — | 闭合约束提供的结构性信息 |

三者合计贡献了本项目验证过的全部有效信号。

## 3. 防泄露设计

这是本项目最重视的部分。**六条硬约束**：

| # | 措施 |
|---|---|
| 1 | **交叉验证按 `source_group_id` 分组** —— 同一篇文献 / 同一矿区的样品绝不跨折 |
| 2 | 插补 / 标准化 / OneHot **只在训练折 fit** |
| 3 | RidgeCV 的 alpha **折内自选**（不引用任何外部调参结论） |
| 4 | **不使用目标编码** —— 243 条 / 136 组下风险高，已实测确认无增益 |
| 5 | 5 个**不同的分组种子**重复评估，报 均值 ± 标准差（不只报最优折） |
| 6 | 特征不含任何目标氧化物（已脚本自检） |

### 3.1 泄露自检结果

```

seed=7      训练/测试来源组重叠数 = 0  ✅
```

| 指标 | 值 | 判读 |
|---|---:|---|
| 训练集内 R²（in-sample） | +0.8026 | — |

## 4. 快速开始

### 4.1 环境

```bash
python >= 3.9
pandas, numpy, scikit-learn, openpyxl, joblib
```

安装：

```bash
pip install -r requirements.txt
```

### 4.2 复现训练与评估

```bash
cd scripts
python train_sio2.py
```

输出：

```
R²   = +0.7092  (sd 0.0143, 范围 +0.6913 ~ +0.7234)
MAE  = 4.406 wt%
RMSE = 6.019 wt%
```

同时生成 `outputs/metrics.json`、`outputs/cv_results.csv`、`outputs/oof_predictions.csv`，
并在 `models/sio2_model.joblib` 保存最终模型。

> **可复现性已验证**：连续两次运行结果完全一致。

### 4.3 用已训练模型预测

准备一个 xlsx 或 csv，至少含以下列：

```
LOI烧失量, _den闭合分母, K2O, province, city, gangue_source_type, material_stage
```

然后：

```bash
python train_sio2.py --predict 你的文件.xlsx
```

结果写入 `outputs/predictions.csv`，新增 `SiO2_预测` 列。

### 4.4 代码内调用

```python
import joblib, sys
sys.path.insert(0, "scripts")
from train_sio2 import predict

model = joblib.load("models/sio2_model.joblib")
pred = predict(model, df)      # df 需含上述 7 列
```

## 7. 方法选择的实证依据

### 7.1 2×2 因子对照：样本权重 × 目标编码

同池、同折、同模型下四格实测：

| 样本权重 | 目标编码 | R² | sd |
|---|---|---:|---:|
| **均匀（本包采用）** | **不用** | **+0.7092** | 0.0143 |
| 均匀 | 入模 | +0.7071 | 0.0170 |
| 来源组平衡 | 不用 | +0.6955 | 0.0146 |
| 来源组平衡 | 入模 | +0.6924 | 0.0230 |

**选择理由**：
1. 评估指标是**样本加权 R²**，故均匀样本权重与评估目标一致
2. 目标编码在 243 条 / 136 组下风险高，且四格差异均在 ±0.02 内（低于跨种子 sd）
3. 配置最简 → 易复现、易部署

### 7.2 已试过但**无效**的方案

为避免后人重复弯路，以下方案均已实测并排除：

| 方案 | 结果 | 原因 |
|---|---|---|
| 加**全硫**（`total_sulfur_pct`） | R² 从 0.71 **跌至 0.30** | 仅来自 **7 个来源组**，伪相关 |
| 加**挥发分 / 固定碳** | R² 0.6935 / 0.6934（无提升） | 仅来自 **2 个来源组** |
| 加**水分** | R² 0.60（sd 0.226） | 与 LOI 高度共线，极不稳定 |
| 加**粒径 / 密度** | 无提升（±0.005） | 覆盖仅 30 条 |
| **保序回归 / 线性 / 二次校准** | ΔR² ≤ 0.005 | 偏差来自特征不足，非预测尺度 |
| **闭合约束**（`closure`） | 完全无变化 | 预测值本就在物理范围内，约束不触发 |
| **目标编码（`city` 53 类）** | −0.0015 | 高基数、样本不足 |

> 这些负结果的共同教训：**任何候选特征进模型前必须先查来源组数**，
> 组数 < 10 的强相关系数一律不可信（已在 `total_sulfur_pct` 上验证：组内 r 高达 −0.638 / +0.567，但加入后模型崩溃）。

## 8. 已知局限

| # | 局限 | 说明 |
|---|---|---|
| 1 | **覆盖范围受限于训练域** | 训练数据以中国 + 巴西为主；预测其他成煤盆地的样品时精度会下降 |
| 2 | **依赖 LOI** | 无 LOI 的样品无法使用本模型（LOI 是唯一强特征，组内 r = −0.722） |
| 3 | **低硅段偏乐观** | SiO₂ < 40% 的样品相对误差偏大（模型倾向高估） |
| 4 | **外部验证仅部分通过** | 中国训练 → 巴西测试 R² = +0.5944（有下降，但保持正向） |
| 5 | **不适用于煤灰** | 本模型针对**煤矸石**（整矸基准）。粉煤灰 / 煤灰为灰基，需另行换算 |
