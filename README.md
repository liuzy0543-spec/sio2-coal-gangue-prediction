# 煤矸石 SiO₂ 含量预测模型

> 用**工业分析 + XRF** 即可获得的少量指标，预测煤矸石的二氧化硅（SiO₂）含量。
> **三种子验证全部 > 0.70**：R² = **0.7272**（0.7117 / 0.7286 / 0.7413），MAE = 4.36 wt%。

---

## 1. 任务与结果

| 项 | 内容 |
|---|---|
| 预测目标 | 煤矸石中 **SiO₂ 含量（wt%）** |
| 输入特征 | LOI（烧失量）、`_den`（闭合分母）、K₂O + 4 个类别字段 |
| 样本量 | **261 条 / 145 个来源组**（含中国 27 省 + 巴西 + 美国宾州）|
| 模型 | RidgeCV（岭回归，alpha 折内自选） |
| **R²（三种子均值）** | **0.7272 ± 0.0148** |
| **R² 范围** | **0.7117 ~ 0.7413** |
| **三种子是否全部 > 0.70** | ✅ **是** |
| MAE | **4.36 wt%** |
| RMSE | 5.96 wt% |
| 相对误差中位数 | **−0.38%** |
| \|相对误差\| ≤ 20% | **88.9%** |

### 1.1 三种子验收结果

| 分组种子 | R² | MAE | RMSE |
|---|---:|---:|---:|
| **42** | **+0.7117** | 4.395 | 6.129 |

| **2024** | **+0.7413** | 4.290 | 5.806 |
| 均值 ± sd | **+0.7272 ± 0.0148** | 4.359 | 5.960 |

> 三种子全部 > 0.70，**最低的 seed=42 也有 0.7117**。

### 1.2 五种子扩展验证（可选，`--seeds 5`）

| 分组种子 | 42 | 7 | 2024 | 13 | 99 |
|---|---|---|---|---|---|
| R² | +0.7117 | +0.7286 | +0.7413 | +0.7399 | +0.7440 |

五种子均值 **0.7331**，全部 > 0.70。

### 1.3 相对误差分布（OOF，seed 42）

| 区间 | 占比 |
|---|---:|
| \|相对误差\| ≤ 10% | 62.8% |

## 2. 输入特征说明

### 2.1 三个数值特征

| 特征 | 定义 | 获取方式 | 成本 |
|---|---|---|---|
| **LOI（烧失量）** | 815 ℃ 灼烧失重（GB/T 212） | **马弗炉** | 极低 |
| **`_den`（闭合分母）** | `MgO + K₂O + Na₂O + TiO₂ + SO₃ + LOI` | XRF 五项 + LOI | 低 |
| **K₂O** | 氧化钾 | **XRF** | 低 |

**`_den` 的物理含义**：煤矸石全分析满足

```
Σ四氧化物(SiO₂+Al₂O₃+Fe₂O₃+CaO) + Σ非目标氧化物(MgO+K₂O+Na₂O+TiO₂+SO₃) + LOI ≈ 100
```

因此 `100 − _den` 近似等于四氧化物的总量份额。`_den` 越低 → 四氧化物占比越高。

> **无标签泄露**：`_den` 只由**非目标**字段构成，不含 SiO₂/Al₂O₃/Fe₂O₃/CaO 任何信息。

### 2.2 四个类别特征

`province`（省）、`city`（市）、`gangue_source_type`（矸石类型）、`material_stage`（原矸/洗矸）

全部 OneHot 编码（`min_frequency=2`，`handle_unknown="ignore"`）。

### 2.3 为什么用这三个数值特征

| 特征 | 与 SiO₂ 的组内相关（去组间均值） | 说明 |
|---|---:|---|
| LOI | **−0.722** | 烧失量高 → 有机质/黏土多 → 硅低 |
| K₂O | **+0.394** | 钾长石/伊利石与石英共生 |
| `_den` | — | 闭合约束提供的结构性信息 |

三者合计贡献了本项目验证过的全部有效信号。

## 3. 防泄露设计

| # | 措施 |
|---|---|
| 1 | **交叉验证按 `source_group_id` 分组** —— 同一篇文献 / 同一矿区的样品绝不跨折 |
| 2 | 插补 / 标准化 / OneHot **只在训练折 fit** |
| 3 | RidgeCV 的 alpha **折内自选** |
| 4 | **不使用目标编码** —— 261 条 / 145 组下风险高，已实测确认无增益 |
| 5 | 多个**不同的分组种子**重复评估，报 均值 ± 标准差（不只报最优折） |
| 6 | 特征不含任何目标氧化物 |

### 3.1 过拟合检查

| 指标 | 值 | 判读 |
|---|---:|---|
| 训练集内 R²（in-sample） | 约 +0.80 | — |
| 三种子 CV R² | +0.7272 | — |
| **差距** | **约 0.07** | 合理（未出现 in-sample ≫ CV 的典型过拟合） |

## 4. 快速开始

### 4.1 环境

```bash
python >= 3.9
pandas, numpy, scikit-learn, openpyxl, joblib
```

安装：

```bash
pip install -r requirements.txt
```

### 4.2 复现训练与评估

```bash
cd scripts
python train_sio2.py            # 三种子验收（默认）
python train_sio2.py --seeds 5  # 五种子
```

输出：

```
    seed=42    R²=+0.7117  MAE=4.395  RMSE=6.129
    seed=7     R²=+0.7286  MAE=4.393  RMSE=5.946
    seed=2024  R²=+0.7413  MAE=4.290  RMSE=5.806
  R²   = +0.7272  (sd 0.0148, 范围 +0.7117 ~ +0.7413)
  >>> 三种子是否全部 > 0.70：是 ✅
```

同时生成 `outputs/metrics.json`、`outputs/cv_results.csv`、`outputs/oof_predictions.csv`，
并在 `models/sio2_model.joblib` 保存最终模型。

### 4.3 用已训练模型预测

准备一个 xlsx 或 csv，至少含以下列：

```
LOI烧失量, _den闭合分母, K2O, province, city, gangue_source_type, material_stage
```

然后：

```bash
python train_sio2.py --predict 你的文件.xlsx
```

结果写入 `outputs/predictions.csv`，新增 `SiO2_预测` 列。

### 4.4 代码内调用

```python
import joblib, sys
sys.path.insert(0, "scripts")
from train_sio2 import predict

model = joblib.load("models/sio2_model.joblib")
pred = predict(model, df)      # df 需含上述 7 列
```

## 7. 方法选择的实证依据

### 7.1 2×2 因子对照：样本权重 × 目标编码

同池、同折、同模型下四格实测（v34 数据 243 条）：

| 样本权重 | 目标编码 | R² | sd |
|---|---|---:|---:|
| **均匀（本包采用）** | **不用** | **+0.7092** | 0.0143 |
| 均匀 | 入模 | +0.7071 | 0.0170 |
| 来源组平衡 | 不用 | +0.6955 | 0.0146 |
| 来源组平衡 | 入模 | +0.6924 | 0.0230 |

**选择理由**：
1. 评估指标是**样本加权 R²**，故均匀样本权重与评估目标一致
2. 目标编码在小样本高基数组别下风险高，且四格差异均在 ±0.02 内（低于跨种子 sd）
3. 配置最简 → 易复现、易部署

### 7.2 已试过但**无效**的方案

| 方案 | 结果 | 原因 |
|---|---|---|
| 加**全硫**（`total_sulfur_pct`） | R² 从 0.71 **跌至 0.30** | 仅来自 **7 个来源组**，伪相关 |
| 加**挥发分 / 固定碳** | 无提升 | 仅来自 **2 个来源组** |
| 加**水分** | R² 0.60（sd 0.226） | 与 LOI 高度共线，极不稳定 |
| 加**粒径 / 密度** | 无提升（±0.005） | 覆盖仅 30 条 |
| 加**石英 / 高岭石 / 伊利石** | 0.7084 / 0.7002 | 仅 64~66 条有数据，插补引入噪声 |
| **保序回归 / 线性 / 二次校准** | ΔR² ≤ 0.005 | 偏差来自特征不足，非预测尺度 |
| **闭合约束** | 完全无变化 | 预测值本就在物理范围内，约束不触发 |
| **高斯过程 GPR** | 0.6873（更差） | 在小样本加性结构下不如线性模型 |
| **Huber / ExtraTrees / RandomForest** | 0.67 / 0.66 / 0.62 | 均不如 RidgeCV |
| **目标变换 log / sqrt / 占比** | 0.41 / 0.46 / 0.44（插补池） | 均更差 |
| **目标编码** | −0.0015 | 高基数、样本不足 |

> **核心教训**：任何候选特征进模型前必须先查来源组数，
> 组数 < 10 的强相关系数一律不可信
> （已在 `total_sulfur_pct` 上验证：组内 r 高达 −0.638 / +0.567，但加入后模型崩溃）。

## 8. 已知局限

| # | 局限 | 说明 |
|---|---|---|
| 1 | **覆盖范围受限于训练域** | 训练数据以中国 + 巴西 + 美国为主；预测其他成煤盆地的样品时精度会下降 |
| 2 | **依赖 LOI** | 无 LOI 的样品无法使用本模型（LOI 是唯一强特征，组内 r = −0.722）|
| 3 | **低硅段偏乐观** | SiO₂ < 40% 的样品相对误差偏大（模型倾向高估）|
| 4 | **不适用于煤灰 / 粉煤灰** | 本模型针对**煤矸石**（整矸基准）。粉煤灰、煤灰为灰基，需另行换算 |
| 5 | **样本仍偏少** | 261 条 / 145 组，相比工业级模型仍属小样本 |
